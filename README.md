# Age Printer C Program

A simple C console program built using Code::Blocks that prompts the user to enter their age and then displays it back to them.

## Requirements

* **C Compiler:** MinGW or GCC[cite: 1, 2]
* **IDE (Optional):** Code::Blocks or any standard C text editor/IDE[cite: 1, 2]

## How to Run

### Option 1: Using Code::Blocks
1. Open Code::Blocks[cite: 1, 2].
2. Create or open the project containing `main.c`[cite: 1, 2].
3. Click **Build and Run** (or press `F9`).

### Option 2: Using Command Line (GCC)
1. Open your terminal or command prompt.
2. Navigate to the folder containing `main.c`.
3. Compile the code:
   ```bash
   gcc main.c -o age_printer
